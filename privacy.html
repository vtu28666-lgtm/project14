1. System Scope & Privacy Commitment

Industrial edge environment & authorized employee data handling

ApproxMAC.AI is an adaptive approximate computing platform engineered for real-time industrial predictive maintenance, machinery vibration anomaly detection, and energy-efficient Multiply-Accumulate (MAC) silicon acceleration.

This Privacy Policy governs the collection, processing, and protection of both employee authentication credentials and high-frequency physical machinery telemetry acquired via onboard edge sensors (including I2C/SPI accelerometers and ADC vibration capture channels).

🔐

2. Employee Authentication & Bcrypt Encryption

Zero plaintext passwords • Salted one-way cryptography

To safeguard operational integrity, access to telemetry and hardware configuration modules requires an authenticated employee profile. We collect:

  • Employee Identity: Full Name, unique Employee ID (e.g., EMP-1042), and internal contact number.
  • Official Email Address: Used for session verification and incident alerting.
  • Profile Imagery: Stored securely on the server with sanitized UUID filenames; accessible exclusively to authenticated personnel.

Cryptographic Password Security: Under no circumstance are employee passwords stored in plaintext. Passwords are irreversibly hashed using the industry-standard Bcrypt ($2b$) algorithm with automated cryptographic salts. Session authorization is maintained via digitally signed JWT bearer tokens with strict expiration timeouts.

📡

3. Machinery Vibration & Edge Sensor Telemetry

Local edge ingestion • Zero external data leakage

Physical edge gateways ingest vibration signals from hardware accelerometers (e.g., MPU-6050, ADXL345, IIS3DWB) and acoustic cavitation microphones. Telemetry characteristics include:

  • Statistical Features: Peak amplitude, Kurtosis, Skewness, RMS, Crest Factor, and Variance extracted locally in real-time.
  • FFT Spectral Data: High-speed discrete Fourier transform frequency bins computed at the edge node.
  • Local Processing: All sensor telemetry is analyzed on the local host or edge FPGA without transmission to third-party public clouds or advertising brokers.
🗄️

4. PostgreSQL Relational Persistence & Integrity

ACID-compliant storage • Automated SQLite failover

Employee records and critical machine anomaly logs are persisted using an enterprise-grade PostgreSQL relational database. In local lab testing or isolated environments, the system seamlessly maintains full data integrity via a local SQLite engine.

Database access is restricted through parameterized SQL bindings and SQLAlchemy ORM layers, completely mitigating SQL injection vulnerabilities.

⚡

5. Dynamic MAC Precision & Audit Logging

Silicon mode switching transparency

To deliver up to 58.6% silicon energy reduction, the system dynamically switches between Exact 16-Bit, Mild Approx (10-Bit), and Aggressive Approx (6-Bit) modes. Mode transition decisions, confidence levels, and energy savings are audited to verify that no safety-critical anomaly was overlooked during approximate computation.

👤

6. Employee Rights & Session Termination

Full self-service management • Explicit logout revocation

Employees have the right to inspect their stored account data via the Profile page, upload updated profile photos, or revoke their active session token at any time by selecting Sign Out.
